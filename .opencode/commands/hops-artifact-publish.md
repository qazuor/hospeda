---
description: Publica un snapshot de artifact cuando el usuario lo solicita
---

Verificá primero el bundle con `hops artifact validate <bundle>`. Mostrá slug,
título, fuentes y versión propuesta; pedí confirmación humana antes de ejecutar
`hops artifact publish <bundle>` porque publicar crea un snapshot persistente.
Informá la versión y URL resultantes. No conviertas este command en un generador
manual de HTML ni publiques remotamente.
