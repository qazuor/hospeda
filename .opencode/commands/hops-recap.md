description: Recap analítico de Hospeda apoyado en hops
---

Este es el command canónico de Hospeda. Ejecutá `hops recap --json` primero para
obtener hechos deterministas del worktree. Después agregá sólo el análisis que
el script no puede producir: cambios y verificaciones de la sesión, hallazgos,
problemas, decisiones, pendientes, riesgos y siguiente paso.

No reconstruyas manualmente branch, issue, Git, DB, servidores ni commits. No
escribas en Engram, Linear, Git ni archivos del proyecto. Marcá cada afirmación
como `verificado`, `inferido` o `pendiente`. Leé sólo diff/status, spec,
closeout, resultados y documentos necesarios.
