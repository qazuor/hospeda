---
description: Muestra el plan y gates de smoke testing de una issue
---

Ejecutá `hops smoke-plan HOS-NNN --json`. Presentá los gates, labels y evidencia
en lenguaje claro; señalá cuando no haya gates registrados. Este command es
read-only: no agregues ni quites labels, no ejecutes smoke tests y no modifiques
Linear, Git o archivos del proyecto.
