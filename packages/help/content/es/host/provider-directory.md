## Qué podés hacer

Buscar proveedores locales de confianza y ver su beneficio para anfitriones en {{link:providerDirectory|Directorio de proveedores}}.

## Cómo se hace

1. Entrá a «Directorio de proveedores»: son proveedores locales de confianza para tu alojamiento. Necesitás tener alojamientos registrados para verlo.
2. Elegí un proveedor para ver su beneficio para anfitriones, su horario y las valoraciones de otros anfitriones.
3. Después de usar su servicio, registrá el uso del beneficio (mirá «Registrar y confirmar usos de un beneficio»).
4. Cuando el proveedor confirma un uso, vas a poder valorarlo. Las valoraciones las escriben anfitriones con un uso confirmado.

## Qué esperar

- Necesitás tener alojamientos registrados para ver el directorio.
- Cada proveedor muestra su beneficio, su horario y las valoraciones de otros anfitriones.
- Después de usar un servicio, {{article:benefit-usage|registrás el uso del beneficio}}.

## Qué NO esperar

- Valorar a un proveedor sin un uso confirmado.
- Que un asistente registre usos por vos.

## Problemas comunes

### El directorio está vacío {#vacio}

Revisá que tengas un alojamiento registrado.

### Soy proveedor y quiero aparecer {#soy-proveedor}

Mirá {{article:benefit-usage-provider|la ayuda para proveedores}}.
